Notation and conventions

Following Ryden, Introduction to Cosmology, 2nd edition

The lectures, homework and exam all use the symbols below. If something you read uses a different name, look it up here. This page grows as the course goes on.

Basic quantities

SymbolNameMeaning
$t_0$present timeThe age of the Universe today. A subscript 0 always means "today".
$a(t)$scale factorThe size of the Universe relative to today, $a(t_0) = 1$.
$z$redshift$z = (\lambda_\text{obs} - \lambda_\text{em})/\lambda_\text{em}$; for cosmological redshift $1 + z = 1/a(t_\text{em})$.
$H(t)$Hubble parameter$H = \dot a / a$.
$H_0$Hubble constant$H(t_0)$. Benchmark value 68 km s⁻¹ Mpc⁻¹.
$H_0^{-1}$Hubble time≈ 14.4 Gyr for $H_0 = 68$ km s⁻¹ Mpc⁻¹.
$c/H_0$Hubble distance≈ 4400 Mpc for $H_0 = 68$ km s⁻¹ Mpc⁻¹.
$\Omega$density parameter$\varepsilon / \varepsilon_c$, energy density relative to the critical density (Lecture 4).
